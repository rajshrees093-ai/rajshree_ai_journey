What's a "loop" prompt?

A normal prompt gets one answer. A loop prompt tells Claude to generate an answer, judge it against criteria you set, and try again if it falls short — automatically, up to a limit you control. Useful when quality matters more than getting an answer on the first try.

What is this?

The Personal AI Playbook is a personal library of reusable AI prompt systems, built around how you use Claude for outreach and client communication. Instead of generic prompts, it's organized around your real bottleneck: sounding consistent while personalizing messages for lots of different people.

The five sections
  • Dashboard — an overview of your library and where to start.
  • Workflow Library — ready-to-use templates. Fill in the blanks, get a prompt.
  • Prompt Builder — build a custom prompt piece by piece, from a role and objective down to a tone and quality checklist.
  • Loop Builder — turn any prompt into one that drafts, self-checks, and revises automatically.
  • Backup & Export — download your library as a file so it's never just sitting in one browser.
